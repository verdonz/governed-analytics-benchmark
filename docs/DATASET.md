# Dataset

The dataset is entirely synthetic. `data/generate.ts` uses a fixed seed and generates a realistic but artificial B2B SaaS / commerce dataset with accounts, contacts, subscriptions, orders, invoices, payments, refunds, web activity, ownership history, and support tickets. It includes 18+ months of date semantics and intentional grain traps.

Code and generated data are released under the MIT license. Generated rows use `example.test` email addresses and do not represent real people or companies. Do not add production data to this repository.
